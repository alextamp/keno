# Keno — πλήρης λίστα features (ό,τι υπάρχει ήδη)

> Σκοπός: λίστα αναφοράς για να ρωτήσεις άλλο εργαλείο/μοντέλο "τι άλλο να προσθέσουμε" χωρίς να προτείνει κάτι που ήδη υπάρχει.
>
> Τελευταία ενημέρωση: 16 Νοε 2026. Η 1.4 είναι στα stores. Το **Keno for Good** (ενότητα στο τέλος) είναι γραμμένο στο branch `feature/keno-for-good`, ενεργό μόνο σε dev builds μέχρι να ενημερωθούν Privacy/Terms — δεν έχει κυκλοφορήσει ακόμα. Το branch περιλαμβάνει και αναβάθμιση σε Expo SDK 58.

## Πυρήνας / Feed
- For-You feed με κατηγορίες (Καφές, Μπάλα/Αθλητικά, Διάβασμα, Πάρτι, Πεζοπορία, Πολιτισμός, Εθελοντισμός, Άλλο)
- Toggle For You / Friends, sort βάσει ενδιαφερόντων
- Φίλτρα: ακτίνα, πότε (σήμερα/αύριο/σαββατοκύριακο), μόνο πανεπιστήμιο, solo-friendly
- Feed ποτέ εντελώς άδειο — fallback σε "opening soon" events + admin-pinned flagship event banner
- 5km χάρτης με τα ίδια φίλτρα
- Αναζήτηση events/ατόμων/κοινοτήτων
- Κάρτα εισόδου στο Keno for Good μέσα στο feed (μόλις ενεργοποιηθεί)

## Events
- Δημιουργία event με περιορισμούς: ηλικία, πανεπιστήμιο, φύλο (male/female/any), solo-friendly tag
- Ιδιωτικά events + αιτήματα συμμετοχής
- Capacity + waitlist με αυτόματη προαγωγή
- Co-hosts
- Edit event μετά τη δημιουργία
- "Find your group" πληροφορία (κείμενο/φωτό) από τον δημιουργό, εμφανίζεται στο check-in
- Επαναλαμβανόμενα events (σειρές, π.χ. κάθε εβδομάδα) με αυτόματη δημιουργία επόμενων εμφανίσεων
- Public event link: web σελίδα για δημόσια events που ανοίγει/κάνει preview χωρίς την εφαρμογή
- Υπενθυμίσεις πριν το event (local notifications) με ρύθμιση χρόνου (30'/1ώ/2ώ) + "Προσθήκη στο ημερολόγιο"
- Rides: προσφορά/κράτηση θέσης σε αυτοκίνητο για ένα event (σημείο συνάντησης ορατό μόνο σε επιβεβαιωμένους)

## Check-in & εισιτήρια
- QR check-in με rotating 30s secret + roll-call fallback (χειροκίνητο)
- Συλλεκτικό Ticket ανά event (unique art, serial number = checkInCount)
- Micro-recap + share-as-image αμέσως μετά το check-in
- Υποχρεωτικό XP staking στη συμμετοχή, κλιμακούμενο στα οικονομικά του χρήστη
- Private reliability score (μη τιμωρητικό) + no-show sweep (scheduled function)
- Stand-in host claim όταν ο δημιουργός δεν εμφανίζεται

## Live Mode (ενεργό event, μετά το check-in)
- Tell-a-friend share
- 🆘 διακριτικό safety button → emergency contact + one-tap 112
- Γρήγορο upload στο photo wall
- "Τερμάτισε το event τώρα" (μόνο δημιουργός)

## Κοινωνικά
- Attendee list με μέτρηση κοινών γνωστών
- Plus-one προσκλήσεις (event ή προφίλ) — XP + Plus One ticket και στους δύο όταν γίνει πραγματικό check-in (όχι μόνο install)
- Follow / DMs — read receipts (Instagram-style "Seen"), push notifications με το πραγματικό περιεχόμενο μηνύματος
- Swipe-to-delete σε DMs, event chats, group chats (με select-all)
- Event chat auto-expire 24h μετά την έναρξη του event
- Kudos reactions σε όσους έκαναν check-in
- Οι ειδοποιήσεις chat στον διοργανωτή στέλνονται μία φορά ανά μήνυμα (ήταν διπλές — διορθώθηκε στο branch)
- Private post-event "πώς ήταν;" feedback για trust του διοργανωτή
- Solo-friendly tag + ticket για πρώτη solo συμμετοχή + welcome ticket πρωτοετών
- Group check-in bonus: 3+ αμοιβαίοι φίλοι check-in στο ίδιο event → Squad ticket + XP

## Photo wall
- Μόνο για όσους έκαναν πραγματικό check-in (όχι lurkers)
- 30-day auto-delete με ειδοποίηση πριν λήξει + δυνατότητα save πριν σβηστεί

## Κοινότητες (Groups)
- Create/join/leave
- Δημόσιες + ιδιωτικές (request-to-join)
- Admin-granted verified-organiser badge
- Dynamic "hero card" expand σε Suggested & My Groups (άγγιγμα → μεγαλώνει η κάρτα)

## Gamification
- XP/levels: Freshman → GOAT (12 επίπεδα) + CEO rung (μόνο για τον ιδρυτή)
- Εβδομαδιαία (όχι ημερήσια) streaks, banked freeze tokens, user-initiated "pause streak" (έως 2/εξάμηνο)
- "Regular" badge (συνέπεια, ξεχωριστό από raw volume)
- "Verified" badge (≥5 check-ins)
- Weekly quests + lifetime challenges (ενοποιημένα σε μία σελίδα "Αποστολές")
- **"Νέος στην πόλη" mode** (νέο): ενεργό μέχρι το πρώτο πραγματικό check-in· badge "ΚΑΙΝΟΥΡΓΙΟΣ" στο προφίλ· μόνο 2 ξεκλείδωτες αποστολές (δημιούργησε event / πήγαινε σε event — βάσει πραγματικού check-in, όχι RSVP), οι υπόλοιπες κλειδωμένες· instant level-up Freshman→Sophomore στο πρώτο event που φτιάχνεις· μεγάλο XP bonus + celebratory οθόνη στο πρώτο check-in, που σε βγάζει από το mode
- **"Έχω κενό" beacon** (νέο): εφήμερο "είμαι ελεύθερος τώρα" σήμα, ορατό σε όλους σε ακτίνα 1χλμ ως ζωντανή κάρτα στο feed (glow/wiggle animation, live countdown)· διάρκεια 30λ/1ώ/2ώ επιλογή χρήστη· tap από άλλον → ανοίγει κατευθείαν DM με context banner + quick-reply· tap στο δικό σου → τερμάτισε νωρίτερα· αυτόματο cleanup

## Wrapped & στατιστικά
- Keno Wrapped εξαμήνου: story slides (εισιτήρια, χάρτης περιοχών, άτομα που γνώρισες, "απόδειξη", persona, εβδομάδες) — share/save ως εικόνα 1080×1920
- Στατιστικά διοργανωτή: προσέλευση vs εγγραφές, no-shows, μοναδικοί/επαναλαμβανόμενοι συμμετέχοντες, ιδιωτικό feedback

## Κατατάξεις (Leaderboards)
- Split "το πανεπιστήμιό σου" / "όλη η Ελλάδα"
- Μόνο check-ins (ποτέ RSVPs), εβδομαδιαία

## Reviews & reconnect
- Ελαφρύ one-tap "recommend" μεταξύ ατόμων που ήταν μαζί σε event
- Post-event "Θα ξαναβρεθούμε;" mutual-swipe flow → DM αν ταιριάξουν

## Ασφάλεια & moderation
- Reporting σε κάθε profile/event (SLA <24h)
- Bidirectional block
- .gr email verification + ID-photo verification fallback (admin review queue)
- Content-moderation filter σε ελεύθερα πεδία κειμένου
- Party events default verified-only
- Δημιουργός μπορεί να περιορίσει event σε women-only (χωρίς ξεχωριστό feed filter γι' αυτό)

## Ειδοποιήσεις
- Behaviour-triggered (friend-going, referral-reward, κλπ), ποτέ γενικά broadcasts
- Push + in-app, per-category opt-out preferences (υπενθυμίσεις, μηνύματα ομάδων, προτάσεις, rides)
- Banner στις ρυθμίσεις όταν οι ειδοποιήσεις είναι κλειστές στο κινητό

## Auth & onboarding
- Progressive sign-up (βήμα-βήμα)
- .gr email verification με custom branded email (Resend)
- ID-photo fallback + pending-verification screen
- Inline sign-in banner όταν λείπει μόνο η ID φωτογραφία

## Settings
- Theme (light/dark), γλώσσα (EL/EN), notification prefs, ενδιαφέροντα, profile visibility, emergency contact, blocked users, feedback/report, legal
- Διαγραφή λογαριασμού με πλήρη καθαρισμό δεδομένων στον server (follows, ομάδες, μηνύματα, φωτογραφίες, rides, swipes, και όλα τα δεδομένα του Keno for Good)

## Admin / ops (εσωτερικά, όχι user-facing)
- Events-ingestion pipeline: auto-import events από εξωτερικές πηγές, auto-publish αν δεν χρειάζεται review αλλιώς review queue, ξεχωριστός "keno" λογαριασμός διαχείρισης
- Admin reports queue, audit log, moderation log
- Ο λογαριασμός "keno" εγκρίνει και τις αποστολές εθελοντισμού φοιτητών, στην ίδια οθόνη "Έγκριση εκδηλώσεων" (πρώτες στη λίστα)
- Έγκριση λογαριασμού ως **οργανισμού** (Keno for Good) από την οθόνη επαλήθευσης — η εγγραφή μένει ίδια, ο admin απλώς τον σημαδεύει
- Admin ουρά ελέγχου φωτογραφιών Keno for Good

# Keno for Good (εθελοντισμός) — στο branch, όχι ακόμα στα stores

Ξεχωριστός "κόσμος" μέσα στην εφαρμογή με πράσινο accent και 4 tabs: **Δράσεις, Κοινότητες, Χαρακτήρας, Κατάταξη**. Ίδιος λογαριασμός με το κανονικό Keno. **Οι πόντοι KfG είναι ξεχωριστό σύστημα από τα XP** — δεν υπάρχει XP staking/anti-flake στις αποστολές.

## Αποστολές (missions)
- Τις φτιάχνουν **φοιτητές** (περνάνε από έγκριση του λογαριασμού "keno") και **οργανισμοί** (δημοσιεύονται αμέσως). Χωρίς μηνιαίο όριο· rate limit 5/ώρα
- 3 τύποι επαλήθευσης: **QR** (ο διοργανωτής σκανάρει το προσωπικό QR του εθελοντή — check-in και check-out μετά από ελάχιστο χρόνο), **ομαδική** (αμοιβαία επιβεβαίωση μεταξύ συμμετεχόντων), **φωτογραφίας** (πριν/μετά με αυτόματο έλεγχο: ώρα, απόσταση, πρόσωπα — EXIF αφαιρείται)
- Σκοποί: Τρόφιμα, Ζώα, Περιβάλλον, Ανακύκλωση, Άνθρωποι, Άλλο
- Φωτογραφία εξωφύλλου, ίδια φίλτρα με τα events (ηλικία/πανεπιστήμιο ελέγχονται και στον server, φύλο ως ετικέτα, solo-friendly)
- Πλήρης επεξεργασία πριν ξεκινήσει· ακύρωση
- Λίστα αναμονής με αυτόματη προαγωγή, αποστολές "με αίτημα συμμετοχής" (με μήνυμα), συνδιοργανωτές (σκανάρουν κι αυτοί), πρόσκληση φίλων
- "Πού θα μας βρεις": κείμενο + φωτογραφία σημείου συνάντησης
- Live Mode: πες σε φίλο, γρήγορη φωτό, 🆘 (emergency contact / 112), "τερμάτισε τώρα" για τον διοργανωτή
- Chat αποστολής (μόνο διοργανωτής + συμμετέχοντες, κλείνει 24ώ μετά την έναρξη)
- Συμμετέχοντες με κοινούς γνωστούς, ✓ για όσους ήρθαν, Kudos, "recommend", "Θα ξαναβρεθούμε;" (match → DM)
- Photo wall (μόνο όσοι ήρθαν, 30 μέρες, ο διοργανωτής μπορεί να το κλείσει π.χ. για καταφύγια/συσσίτια)
- Κοινοποίηση με public web σελίδα αποστολής + "Στο ημερολόγιο" + υπενθυμίσεις πριν την έναρξη
- Αποστολές στον κανονικό χάρτη (πράσινες πινέζες, chip "Εθελοντισμός"), αναζήτηση και chips σκοπού στο tab Δράσεις
- "Οι αποστολές μου" με κατάσταση (σε αναμονή / δημοσιευμένη / δεν εγκρίθηκε / ολοκληρώθηκε)
- Ειδοποιήσεις: έγκριση/απόρριψη, νέος εθελοντής, ακύρωση, νέα αποστολή στην κοινότητα, θέση από λίστα αναμονής, αιτήματα, προσκλήσεις, μηνύματα

## Πόντοι, επίπεδα, χαρακτήρας
- Πόντοι μόνο από τον server (όχι από την εφαρμογή): οργανισμοί 200–300, φοιτητικές 150 (μετρούν μόνο με ≥3 επαληθευμένους), φωτογραφίας 40 (δεν μετρούν στην κατάταξη)
- 10 επίπεδα (Αρχάριος → Θρύλος), εβδομαδιαίο streak
- **Χαρακτήρας** (avatar εθελοντή): 6 δωρεάν χαρακτήρες (Κλασικός, Σκυλάκι, Γατούλα, Αρκουδάκι, Αλεπουδίτσα, Κουνελάκι)
- **Ντουλάπα** αξεσουάρ σε 3 θέσεις (κεφάλι/πρόσωπο/λαιμός): αγορά με πόντους, ξεκλείδωμα με επίπεδο, μετάλλιο top-100
- Σύνδεση με το κανονικό προφίλ: κάρτα KfG στο προφίλ σου και στα προφίλ άλλων, και το προφίλ σου στο tab Χαρακτήρας

## Εισιτήρια, Wrapped, στατιστικά
- Εισιτήριο ανά ολοκληρωμένη αποστολή (σειριακός αριθμός), share ως εικόνα, μαζί με τα υπόλοιπα στο "Τα εισιτήριά μου"
- Keno for Good Wrapped εξαμήνου: χαρακτήρας, αποστολές ως εισιτήρια, "απόδειξη εθελοντισμού" (ώρες, πόντοι, οργανισμοί)

## Κοινότητες
- Ίδιες με τις Παρέες (μέλη, chat, ιδιωτικές, αιτήματα, προσκλήσεις) αλλά ξεχωριστές από αυτές· οι αποστολές δημοσιεύονται σε κοινότητα

## Κατάταξη
- Μηνιαία κατάταξη (μόνο πόντοι που μετράνε), σχολές, εβδομαδιαία μεταβολή θέσης, top-100 μετάλλιο

## Σε εξέλιξη (16 Νοε 2026 — ακόμα όχι ολοκληρωμένα)
- Ιδιωτικό "πώς ήταν;" μετά την αποστολή + στατιστικά διοργανωτή για αποστολές (γραμμένα, θέλουν τελικό έλεγχο)
- Rides για αποστολές (υπάρχει ήδη ο διακόπτης στη φόρμα, όχι η οθόνη)
- Επαναλαμβανόμενες αποστολές
- Περισσότεροι χαρακτήρες και αξεσουάρ
- Εκκρεμεί πριν τα stores: Privacy/Terms για το KfG, Cloud Vision API, τεστ σε πραγματικό build
